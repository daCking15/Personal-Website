Tanks 3D

The summer after I graduated in the midst of the COVID-19 pandemic, when I wasn't applying for jobs, I was building my first major solo video game project. The core idea was to turn Addicting Games' cult classic, Tanks, into a full fledged 3D multiplayer game with ambitions of putting it on the Xbox store. A couple months later, I was hired by Equality Lab, and the project was never finished, but the alpha builds I have are pretty cool if not a little buggy. The Windows version is the most stable and definitive version. While the Web GL version may be compatible on more devices, certain features may be broken including the radar and text running off the screen in the main menu. You do need to run a server in order to play the Web GL version, but perhaps I will deploy it when I get a chance and maybe even make a v2. I'm aware there is no sound in the video demo, I will try to record a new one once I run the Windows build.
